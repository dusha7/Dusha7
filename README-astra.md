# 🔮 Астра — эзотерический Telegram-бот

Платный бот-консультант: **Таро, нумерология, астрология**. Главная фишка —
**быстрый ответ**: человек просто пишет вопрос, и Астра сразу отвечает.

- **Быстрый ответ** — любой текст → мгновенный живой ответ (с индикатором «печатает…»).
- **Услуги** через меню: расклад Таро, нумерологический разбор, натальная астрология.
- **Реальные расчёты, не выдумка** — карты вытягиваются в коде, числа считаются в коде,
  положения планет и асцендент считаются по эфемеридам (`astronomy-engine`).
- **Оплата Telegram Stars (XTR)** — без эквайринга и юрлица, работает по всему миру.
- Первые запросы бесплатно, дальше — пакеты запросов за звёзды.
- Память последних реплик → работают уточняющие вопросы.

## Как это устроено

| Файл | Назначение |
|------|-----------|
| `api/telegram.js` | Вебхук (serverless-функция Vercel), вся оркестрация |
| `lib/astra/prompt.js` | Системный промпт Астры (быстрый + структурные услуги) |
| `lib/astra/anthropic.js` | Вызов Claude (`claude-opus-5`, low effort — быстро) |
| `lib/astra/tarot.js` | Колода + честная вытяжка карт (crypto RNG) |
| `lib/astra/numerology.js` | Число Жизненного Пути и Число Души (мастер-числа 11/22/33) |
| `lib/astra/astrology.js` | Знаки, стихии, Луна, планеты, асцендент + геокодинг города |
| `lib/astra/store.js` | Upstash Redis: баланс, бесплатные запросы, память, идемпотентность |
| `lib/astra/telegram.js` | Обёртка Bot API: сообщения, инвойсы Stars, санитайзер HTML |
| `lib/astra/config.js` | Тарифы, лимиты, модель — всё настраивается здесь |
| `scripts/set-webhook.js` | Регистрация вебхука в Telegram |

## Запуск за 4 шага

### 1. Ключи и база

- **Бот:** напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи `ASTRA_BOT_TOKEN`.
  Затем `/mybots → Payments` — Stars включены по умолчанию, отдельный провайдер не нужен.
- **Claude:** ключ на [console.anthropic.com](https://console.anthropic.com) → `ANTHROPIC_API_KEY`.
- **Redis:** заведи бесплатную базу на [upstash.com](https://upstash.com) → раздел **REST API** →
  `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

Смотри `.env.astra.example` — там все переменные.

### 2. Деплой на Vercel

Проект уже готов к Vercel (функции в `api/`). Задеплой репозиторий и добавь
переменные окружения в **Settings → Environment Variables** (значения из шага 1).
Придумай любой `ASTRA_WEBHOOK_SECRET` (случайная строка) — он защитит вебхук.

### 3. Привязать вебхук

Локально, подставив свой домен Vercel:

```bash
export ASTRA_BOT_TOKEN=123456:ABC...
export ASTRA_WEBHOOK_SECRET=любая-случайная-строка   # тот же, что в Vercel
BASE_URL=https://your-app.vercel.app npm run set-webhook
```

Должно вернуться `{ ok: true, result: true, description: 'Webhook was set' }`.

### 4. Проверить

Открой бота в Telegram, нажми **Start**, напиши любой вопрос — Астра ответит.
Тапни услугу в меню — пойдёт структурный разбор. Когда бесплатные запросы кончатся,
бот предложит купить пакет за звёзды ⭐.

## Настройка

Всё в `lib/astra/config.js`:

- `FREE_QUESTIONS` — сколько запросов бесплатно (по умолчанию 3).
- `PACKAGES` — пакеты и цены в звёздах.
- `MODEL` — модель (по умолчанию `claude-opus-5`; для максимальной скорости
  поставь `ASTRA_MODEL=claude-haiku-4-5` в переменных окружения).
- `MAX_TOKENS_QUICK` / `MAX_TOKENS_READING`, `EFFORT`, `MEMORY_TURNS`.

## Заметки

- **Возвраты звёзд:** при необходимости — метод Bot API `refundStarPayment`
  (по `telegram_payment_charge_id`, который бот сохраняет при оплате).
- **Астрология с планетами и асцендентом** требует, чтобы функция могла ходить
  в `geocoding-api.open-meteo.com` (на обычном Vercel доступ открыт). Если город
  не определился — Астра корректно откатывается к разбору по знаку Солнца.
- **Границы Астры** (без предсказаний смерти/болезней и без запугивания «порчей»)
  заданы в `lib/astra/prompt.js` — это защищает бота от блокировок платёжных систем.
